    How It Works

    Seven automated stages analyze claims, code, coordination patterns, and timelines — then synthesize a trust score with evidence.

    1

    Intake

    Classify URLs — tweets, repos, wallets, websites. Extract metadata and route to appropriate scrapers.

    2

    Scrape

    Pull post data via fxtwitter, repo metadata via GitHub API, wallet profiles from Polymarket.

    3

    Network Map

    Find coordinated accounts, shared bio affiliations, mutual amplification, bare-link seed posts.

    4

    Code Audit

    Scan for malicious deps, wallet drainers, postinstall hooks, API key exfiltration vectors.

    5

    Claim Verify

    Extract profit claims with regex, cross-reference against on-chain wallet data and Polymarket positions.

    6

    Timeline

    Detect seed→amplification→hype patterns. Find the densest posting windows and clustering anomalies.

    7

    Report

    Weighted scoring formula synthesizes all stages into a trust score with verdict and evidence list.

    Transparent Scoring

    Trust Score =
      30% × Code Audit Score
    + 30% × Claims Verification Score
    + 20% × (100 − Coordination Score)
    + 20% × (100 − Clustering Score)
    − 5pts × each unverifiable claim >$100K
    75-100: LEGIT 35-74: SUSPICIOUS 0-34: LIKELY HYPE
